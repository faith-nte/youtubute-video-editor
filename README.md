# CLI video editing skill

This repository keeps Faith's reusable Codex workflow for editing existing videos from the command line. It covers full-timeline privacy review, anonymized screen replacement, caption cleanup, scene transitions, and export checks.

The skill lives in [`skills/cli-video-editing`](skills/cli-video-editing). To install it for Codex, copy that folder into `$CODEX_HOME/skills/` or, when `CODEX_HOME` is unset, `~/.codex/skills/`.
